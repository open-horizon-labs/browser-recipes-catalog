# Hacker News

Both recipes navigate an open Hacker News tab and return the first story title in `outputs.headline`.

- `front-page` reads the top story on `/news`. [Recipe](recipes/front-page.json)
- `newest` reads the latest submission on `/newest`. [Recipe](recipes/newest.json)

**Origin** `https://news.ycombinator.com` · [Shared targets](adapter.json)
