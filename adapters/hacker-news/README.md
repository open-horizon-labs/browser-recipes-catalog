# Hacker News

Read the leading headline from either the front page or the newest submissions. Both recipes reuse the same headline selector.

Start with an open Hacker News tab. Each recipe navigates the tab to its listing and returns the first story title in `outputs.headline`.

- [front-page](recipes/front-page.json) — Read the leading front-page headline.
- [newest](recipes/newest.json) — Read the newest headline.

**Origin** `https://news.ycombinator.com` · [Shared targets](adapter.json)
