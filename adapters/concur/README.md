# SAP Concur Expense

Run `first-expense-report-summary` in a signed-in US2 Concur tab to get the visible text of the first active report card in `outputs.summary`. The recipe opens Manage Expenses and checks the English heading. The account needs at least one active report. [Recipe](recipes/first-expense-report-summary.json)
