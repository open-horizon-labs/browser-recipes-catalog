# Outlook on the web

Read the summary of the first message row in the current Outlook folder without opening the message.

Open a populated folder in a signed-in tab and scroll to the top. The recipe reads the visible text of the row at list position one into `outputs.summary`. The selector uses the English “Message list” label.

- [first-message-summary](recipes/first-message-summary.json) — Read the first message row in the current Outlook list.

**Origin** `https://outlook.cloud.microsoft` · [Shared targets](adapter.json)
