# Gmail

Read a subject from the folder or message list you already have open. This works for checking the top item in Inbox or Sent without opening the conversation.

The recipe reads the first rendered subject into `outputs.subject`. Start in a signed-in Gmail tab with a populated message list.

- [first-visible-subject](recipes/first-visible-subject.json) — Read the first subject in the current Gmail message list.

**Origin** `https://mail.google.com` · [Shared targets](adapter.json)
